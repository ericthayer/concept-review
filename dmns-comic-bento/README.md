# DMNS Comic Bento (concept)

A concept redesign of [dmns.org](https://www.dmns.org/) as a living comic book laid out on a
bento grid. Every screen is a comic page, every grid cell a panel. Hours, tickets and the
active notice stay plain and one glance away on every page.

Concept only: tickets, membership, giving, login and search link out to the live site.
Not the official museum website.

## Run it

```sh
npm install
npm run dev        # build, then serve dist/ at http://localhost:4321
npm run build      # tsc → build/client, then scripts/build.ts → dist/
npm run check      # typecheck, lint, unit, build, contrast, budgets, links, reading order, Playwright
```

Node 22.18+ (TypeScript runs natively through type stripping; no bundler). `BUILD_DATE=YYYY-MM-DD`
pins "today" for notice expiry and "Now open" labels. Netlify: set the site's base directory to
`dmns-comic-bento/`; `netlify.toml` builds `dist/`.

## How it fits together

```
content/*.json ──typed loaders (src/lib/content.ts)──▶ templates (src/templates) ──▶ dist/**/index.html
                                                     │
src/lib/routes.ts ──▶ PagePosition per route ────────┤──▶ <script id="book-map"> inlined per page
src/lib/layouts.ts ──▶ grid-template-areas CSS ──────┘
src/main.ts ──▶ custom elements + pageswap/pagereveal (JS upgrades only; every page works without it)
```

### Route → position → camera move → CSS

| Route | Issue | Depth | Order |
|---|---|---|---|
| `/` | cover | 0 | 0 |
| `/halls/`, `/special-exhibitions/`, `/theaters/`, `/visit/`, `/programs/`, `/learn/`, `/science/`, `/about/`, `/support/` | that issue | 1 | nav order |
| `/halls/{slug}/` | halls | 2 | floor, then source order |
| `/special-exhibitions/{slug}/` | special | 2 | source order |
| `/theaters/{slug}/` | theaters | 2 | source order |

```
resolveCameraMove(from, to)
  same path ......................................... none
  depth equal, issue differs ........................ new-issue   → :active-view-transition-type(new-issue)
  depth equal, same issue, order up / down .......... turn-next / turn-prev
  depth up / down ................................... zoom-in / zoom-out (panel ⇄ splash, caption ⇄ h1)
```

Examples (unit-tested in `tests/unit/content.test.ts`): Cover → Halls and Halls → Prehistoric Journey
zoom in; Prehistoric Journey → Halls zooms out; Prehistoric Journey → Egyptian Mummies turns the page;
Halls → Theaters is a new issue. Choreography lives in `src/styles/camera.css`; see `docs/motion-spec.md`.
